Tableau ASCII
-------------
Une application qui permet de faire des tableaux comme ceux générés par MySQL
par exemple.
- écrivez votre texte séparé par des ; dans le champ tout en haut.
- Puis appuyez sur "Convertir" pour générer le tableau, il apparait dans le champ
tout en bas.
- Cliquez sur "Copier" pour copier le texte dans votre presse papiers.
- Le bouton "Effacer" efface ce que vous avez tappé dans le premier champ + le
tableau généré.
Vous pouvez changer le séparateur de données ainsi que la largeur maximale du
tableau généré, lorsque le tableau atteint la largeur maximale, le texte passe
à la ligne dans les cellules.
Le bouton "Valeurs par défaut" permet de rétablir le séparateur et la largeur
par défaut.
Vous pouvez la lancer depuis les réglages rapides ou l'écran d'accueil.
Vous devez utiliser une police régulière dans l'application concernée comme monospace ou mono...
ou regular... pour que le tableau soit affiché sans décalages lors de la lecture.

Compatibilité : Android 4.0.1+


Éditeur de texte
----------------
Un éditeur de texte simple, léger et compatible avec les appareils anciens.
Conçu pour être rapide, minimaliste et fiable, sans dépendances lourdes ni
fonctionnalités superflues.

Fonctionnalités :
- Thème noir ou sombre avec opacité et taille du texte réglables (menu style)
- Multi-onglets
- Boutons ↑ et ↓ pour aller tout en haut ou tout en bas du fichier
- Recherche et remplacement de texte multiligne (menu rechercher)
- Ajouts/suppressions de débuts/fin de ligne
- Dupliquer ou supprimer la ligne courante
- Inverser la ligne courante avec celle du dessus
- Mode dessin pour tracer des formes et placer du texte n'importe-où

Raccourcis clavier (clavier physique ou Unexpected Keyboard) :
- Ctrl + Z : Annuler
- Ctrl + Y ou Ctrl + Shift + Z : Rétablir
- Ctrl + A : Tout sélectionner
- Ctrl + C : Copier
- Ctrl + V : Coller
- Ctrl + X : Couper
- Ctrl + S : Sauvegarder
- Ctrl + R : Recharger le fichier
- Ctrl + F : Ouvrir le menu Rechercher et remplacer
- Ctrl + J : Copier la ligne dans le presse-papiers
- Ctrl + D : Dupliquer la ligne
- Ctrl + M : Échanger la ligne du curseur avec celle du dessus
- Ctrl + Shift + L : Appliquer les ajouts/suppressions de texte de début/fin de lignes
- Ctrl + Shift + D ou Ctrl + K : Supprimer la ligne
- Ctrl + Shift + T : Transformer en tableau
- Ctrl + Shift + C : Transformer en CSV
- Flèches : Navigation
- Shift + Flèches : Sélection

Notes :
- L'application lit et écrit en UTF-8.
- Les caractères invalides apparaissent sous la forme du symbole �.
- La taille de police suit les réglages du système.

Compatibilité : Android 4.4+


Extracteur Couleur
-----------------------
Permet d'extraire le code couleur à l'écran au format HEX, RGB, HSL, HSV
Vous pouvez la lancer depuis les réglages rapides ou l'écran d'accueil.
Cette application utilise PROJECT_MEDIA, pour accorder l'autorisation permanente :
Commande adb : adb shell appops set com.gabriel.extracteurcouleurs PROJECT_MEDIA allow
Ou configurer et installer Shizuku et App Ops puis accorder cette autorisation
à l'application.

Compatibilité : Android 5.0+


Sélecteur Couleur

Serveur HTTP
------------
Démarrer un serveur HTTP local.
Pour vous connecter au serveur :
Depuis votre serveur ou un autre appareil du réseau : http://ipserveur:8080
Un fichier 404.html à la racine du site est la destination en cas de navigation vers fichier inexistant.

Depuis votre serveur : http://ipserveur:8080 ou http://localhost:8080 ou http://127.0.0.1:8080
ou http://0.0.0.0:8080

Arbo
----
Génèrer une arborescence de dossiers et fichiers dans un fichier arbo.html
Les couleurs des éléments peuvent être changés.
Le nom de la racine peut être changée.
Chaque fichier est un lien menant vers lui, une flèche à droite pour le télécharger.
Ajouter un chemin comme /storage/emulated/0/Documents.
Fonctions export/import de l'ensemble des profils dans un champ de texte.

Compatibilité : Android 4.0.1+
